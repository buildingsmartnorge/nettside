buildingSMART standards and services

buildingSMART develops and maintains standards for the digitization of the construction industry in open formats. There are three international standards that describe and support construction projects. These are essential for being able to use openBIM in practice.

IFC

An industry-specific file format for the exchange of building information modeling (BIM).

Read more

BCF

A workflow and communication format linked to IFC models. The BCF format is based on XML, and the idea is to manage all major and minor issues along the way and ensure traceability and history in the model throughout.

Read more

bSDD

A dictionary or a terminology library. Here, concepts, units of measurement, and properties are uniquely defined with their own unique identity, a so-called GUID (global unique identifier), which is a machine-readable code. This way, for example, a door remains a door regardless of language or national regulations.

Read more

openCDE

It is a standardized approach for managing and storing project-related information digitally in the construction industry, which promotes collaboration and efficiency through a common digital platform for all project participants.

Read more

IDS

A machine-readable format for communicating requirements for information exchange, especially within "Building Information Modeling (BIM). The format enables automatic checking of models and ensures accuracy and effective collaboration between different disciplines.

Read more

IDM

Kort beskrivelse av tjenesten. Forklar fordelene og funksjonene.

Read more

MVD

Specification of data model exchange. An MVD documentation must describe which subset of the IFC data model is necessary to include in an exchange. This way, the exchange can be carried out according to the users' information requirements.

Read more
